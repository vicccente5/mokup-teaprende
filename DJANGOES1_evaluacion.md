## Propósito de la evaluación
El objetivo de esta evaluación es desarrollar una aplicación web básica utilizando Django, aplicando conceptos fundamentales de programación y arquitectura web.
El proyecto debe estar inspirado en un Objetivo de Desarrollo Sostenible (ODS), abordando un problema real mediante una solución digital.

## Descripción del trabajo
Se deberá diseñar e implementar una aplicación web que:
* Resuelva un problema concreto basado en un ODS.
* Utilice el framework Django.
* Integre lógica de programación básica.
* Sea funcional y coherente.

## Requerimientos obligatorios
El proyecto debe cumplir con los siguientes elementos:

1. **Proyecto Django**
   * Crear un proyecto Django correctamente configurado.
   * Incluir al menos una aplicación.
2. **Rutas (URLs)**
   * Definir rutas en `urls.py`.
   * Permitir navegación entre al menos 2 vistas.
3. **Vistas (Views)**
   * Implementar funciones o clases que gestionen la lógica.
   * Retornar respuestas HTTP.
4. **Modelos (Models)**
   * Crear al menos 1 modelo.
   * Incluir mínimo 3 atributos.
   * Aplicar migraciones correctamente.
5. **Templates**
   * Utilizar HTML con el sistema de templates de Django.
   * Mostrar información dinámica desde las vistas.
6. **Lógica de programación**
   * Uso de variables.
   * Uso de estructuras condicionales (`if`).
   * Uso de ciclos (`for`, `while` si aplica).

## Condición del proyecto (ODS)
Se debe seleccionar un ODS y:
* Describir el problema abordado.
* Justificar la solución propuesta.
* Relacionar claramente la aplicación con los ODS seleccionados.

## Entregables
Se deben entregar los siguientes elementos:

1. **Proyecto Django**
   * Carpeta completa del proyecto.
   * Debe ser ejecutable sin errores.
2. **Informe**
   * Debe incluir:
     * Nombre del proyecto.
     * Introducción.
     * ODS seleccionado.
     * Problema identificado.
     * Descripción de la solución propuesta.
     * Funcionalidades principales.

## Presentación
El proyecto es de carácter presencial.
* **Duración:** Máximo 10 minutos.
* **Contenido mínimo:**
  * Problema abordado (ODS).
  * Solución planteada.
  * Demostración del sistema funcionando.
  * Explicación básica de: Models, Views, Templates.

## Criterios de evaluación (Resumen)
Se evaluará:
* Uso de variables y operaciones.
* Lógica del programa.
* Implementación de Django.
* Uso de modelos, vistas y templates.
* Coherencia del proyecto con el ODS.
